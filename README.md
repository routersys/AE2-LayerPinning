# レイヤー固定 for AviUtl ExEdit2

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![AviUtl ExEdit2](https://img.shields.io/badge/AviUtl%20ExEdit2-2.1.0%20or%20later-orange.svg)](#)

---

AviUtl ExEdit2 のレイヤー編集で、先頭から連続したレイヤーを表示領域の最上部へ固定するプラグインです。
固定したレイヤーは、タイムラインを縦へスクロールしても位置が変わりません。固定していないレイヤーだけが固定行の下を流れます。
固定した状態はシーンごとに保持します。
動作を確認した版では、固定行を AviUtl ExEdit2 自身が描きます。

## 概要

本プラグインは AviUtl ExEdit2 の汎用プラグインとして動作します。「その他」の「プラグイン情報」には、名前を「レイヤー固定」、種別を「汎用プラグイン」として表示します。レイヤー編集の右クリックメニューへ、レイヤーを固定する項目と、固定を解除する項目を追加します。

AviUtl ExEdit2 は、レイヤー編集の各行へ、表示開始レイヤー番号に行番号を足したレイヤーを描きます。本プラグインは、この対応を固定範囲の行だけ変えます。固定範囲の行では行番号そのもののレイヤーを描き、それ以外の行では従来どおりの番号のレイヤーを描きます。表示開始レイヤー番号は、行の描画が終わった時点で必ず元の値へ戻します。スクロールの量は AviUtl ExEdit2 が決めます。本プラグインが変えるのは、行とレイヤーの対応だけです。

動作を確認した版では、AviUtl ExEdit2 が1回の描画で正しい配置の絵を描き上げます。プラグインが画面を取得し直したり、余分な再描画を要求したりする必要がないため、固定行は他の行とまったく同じタイミングで更新されます。版が一致しない場合は、固定行を画面から取得して子ウィンドウへ重ねる方式へ切り替わります。表示の内容は変わりませんが、固定行の更新が他の行より遅れ、描画の負荷が増えます。

固定した状態はメモリ上だけで保持します。プロジェクトファイルへは書き込まず、AviUtl ExEdit2 を終了すると解除されます。

## インストール方法

1. [Releases](https://github.com/routersys/AE2-LayerPinning/releases/latest) ページから `LayerPinning_v1.0.0.au2pkg.zip` をダウンロードしてください。
2. AviUtl ExEdit2 を起動し、ダウンロードしたファイルをプレビュー画面へドロップします。
3. 確認の画面で「このプラグイン・スクリプトを信頼して使用する」を選んでください。インストールの後に AviUtl ExEdit2 が再起動します。

手動で配置する場合は、`LayerPinning_v1.0.0.zip` を展開し、`LayerPinning.aux2` を下記のフォルダーへ置いてください。次に AviUtl ExEdit2 を起動すると確認の画面が出るので、信頼して使用することを選びます。

```
C:\ProgramData\aviutl2\Plugin\
```

## 主な機能

### 1. レイヤーの固定と解除

レイヤー編集のタイムライン側で、オブジェクトの無い場所を右クリックします。開いたメニューの「プラグイン」から「レイヤーを固定」を選ぶと、その行のレイヤーまでを固定します。解除は同じ場所の「レイヤーの固定を解除」です。

固定できるのはレイヤー1から連続した範囲だけです。この形を保つため、メニューの項目は次の2種類のレイヤーにだけ表示され、それ以外のレイヤーでは項目そのものが現れません。

- すでに固定しているレイヤー … 「レイヤーの固定を解除」
- 固定範囲のすぐ次のレイヤー … 「レイヤーを固定」

何も固定していない状態では、レイヤー1にだけ「レイヤーを固定」が出ます。レイヤー1を固定すると、レイヤー2にも出るようになります。

範囲が連続した形から外れないよう、途中のレイヤーの固定を解除すると、それより後ろの固定も同時に外れます。レイヤー1からレイヤー3までを固定した状態でレイヤー2の固定を解除すると、レイヤー3の固定も外れ、レイヤー1だけが固定された状態になります。

### 2. 固定行に対する操作

固定行の上のクリックと右クリックメニューは、そこに見えているレイヤーに対して働きます。レイヤーの選択も、レイヤーのロック、レイヤーの表示、レイヤー名の変更といった AviUtl ExEdit2 のメニューも、表示されているとおりのレイヤーが対象になります。固定行のレイヤー名の欄で開くメニューも同じです。

固定行から固定していない行へのオブジェクトのドラッグ移動も、落とした行に表示されているレイヤーへ移ります。

固定行を操作した直後は、スクロールの位置をそのまま保ちます。AviUtl ExEdit2 からは先頭のレイヤーを選択したように見えるため、そのままではタイムラインが先頭へ戻ります。これを避けるため、操作の直後の一定時間だけ位置を保持し直します。ホイールやキーによるスクロールの操作は、この保持より優先されます。

### 3. 描画方式

本プラグインは、最初にレイヤーを固定したときに AviUtl ExEdit2 の実行ファイルを照合します。ファイルの大きさと SHA-256 が動作を確認した版と一致し、なおかつ行の描画に関わる箇所の命令列も一致した場合にだけ、AviUtl ExEdit2 自身へ直接描かせる方式を使います。

この方式では、AviUtl ExEdit2 が1行を描く直前に表示開始レイヤー番号を差し替え、行の並びを描き終えた時点で元の値へ戻します。差し替える対象は、レイヤー編集が行を並べる2つの処理です。プラグインの側から描画を起こす必要がないため、固定行と他の行の間に更新のずれが生じません。

行を描き始める位置と、行の並びを描き終える位置を捉えるために、プロセスのデバッグレジスタを使います。AviUtl ExEdit2 の機械語は書き換えません。実行ファイルは照合のために読むだけで、書き込みは行いません。

照合が一致しない場合は、固定行を画面から取得して子ウィンドウへ重ねる方式で動作します。この方式では、固定行を描かせるために表示開始レイヤー番号を一時的に0へ変えて描き直させ、その結果を取得します。表示の内容は直接描かせる方式と同じですが、取得と描き直しの分だけ更新が遅れ、描画の負荷が増えます。

右クリックメニューの項目を出し分けるため、いずれの方式でも `TrackPopupMenu` のインポートアドレステーブルを書き換えます。メニューを開く直前に対象のレイヤーを調べ、条件に合わない項目をメニューから取り除くためです。

### 4. 表示開始レイヤー番号の探索

固定の処理は、AviUtl ExEdit2 が内部に持つ表示開始レイヤー番号の位置を必要とします。位置の突き止め方は方式によって違います。

直接描かせる方式では、AviUtl ExEdit2 が行を描くときに辿るポインタから位置を割り出します。値を書き換えることも、メモリを走査することもありません。最初に行が描かれた時点で位置が判るため、レイヤーの数に関わらず固定はすぐに効き始めます。

取得して重ねる方式では、表示開始レイヤー番号を SDK から読み書きしながらメモリを走査して位置を突き止めます。この走査には、縦にスクロールできるだけのレイヤーが必要です。オブジェクトがほとんど無いプロジェクトでは位置を突き止められないため、その状態で固定してもすぐには効果が出ません。レイヤーが増えて縦にスクロールできるようになった時点で自動でやり直すので、素材を置けばそのまま固定が効き始めます。走査の間はレイヤー編集の表示が一時的に乱れます。

シーンを切り替えたときは、位置を捨てて割り出しをやり直します。

## メニュー項目

レイヤー編集で、オブジェクトを選択していない状態の右クリックメニューの「プラグイン」に追加されます。

| 項目名 | 表示される条件 | 動作 |
|---|---|---|
| レイヤーを固定 | 固定範囲のすぐ次のレイヤーで、なおかつ固定した後も固定しない行が1行以上残るとき | そのレイヤーまでを固定します |
| レイヤーの固定を解除 | すでに固定しているレイヤー | そのレイヤーとそれより後ろの固定を解除します |

---

## 制限事項

- 固定できるのはレイヤー1から連続した範囲だけです。任意のレイヤーを個別に固定することはできません。
- 表示できる行のうち、必ず1行は固定できないように制限しています。すべての行を固定するとスクロールできなくなるためです。ウィンドウを小さくしたり、レイヤーの縦幅を変えたりして表示できる行数が減った場合は、固定の表示も1行を残すところまで自動で縮みます。
- 縦にスクロールしている間は、レイヤーを追加で固定できません。固定範囲のすぐ次のレイヤーが固定行の裏に隠れて見えないためです。一番上までスクロールしてから固定してください。
- 固定した状態はプロジェクトファイルへ保存されません。AviUtl ExEdit2 を終了すると解除されるため、次に開いたときは固定し直してください。
- 表示開始レイヤー番号の位置を突き止められない間は、固定が有効になりません。この場合もエラーにはならず、本プラグインを入れていない状態と同じ表示になります。
- 取得して重ねる方式では、位置を突き止めるためのメモリの走査中にレイヤー編集の表示が一時的に乱れます。直接描かせる方式では走査そのものを行わないため、この乱れは起きません。
- レイヤー名の欄の上での右クリックでは、AviUtl ExEdit2 の別のメニューが開きます。このメニューにはプラグインの項目が含まれません。タイムライン側で右クリックしてください。

## 注意事項

- 内部実装への依存: 固定の処理は AviUtl ExEdit2 の内部の表示状態に依存しています。AviUtl ExEdit2 の更新で内部の構造が変わり、表示開始レイヤー番号の位置を突き止められなくなった場合は、固定が無効になるだけでエラーにはなりません。
- 描画方式の切り替え: 直接描かせる方式は、実行ファイルの照合がすべて一致した場合にだけ使います。一致しない場合は取得して重ねる方式へ自動で切り替わります。どちらの方式で動作しているかはログ表示から確認できます。
- 遅延した初期化: 起動の直後には何もしません。座標の計測も、表示開始レイヤー番号の探索も、最初にレイヤーを固定した時か、AviUtl ExEdit2 からシーンの変更が通知された時まで遅らせています。
- 設定ファイル: 本プラグインは設定ファイルを作りません。ディスクへの書き込みも行いません。
- 本プラグインを使用する前に、プロジェクトファイルのバックアップを作成することを推奨します。

## ログ表示での確認

「表示」から「ログ表示」を開くと、本プラグインの状態を確認できます。本プラグインの行には `[PLUGIN] [Plugin::LayerPinning.aux2]` が付きます。

| メッセージ | 意味 |
|---|---|
| レイヤー固定: 本体に直接描かせる方式を使えます | 実行ファイルの照合が一致しました |
| レイヤー固定: 直接描画を有効にしました | 直接描かせる方式で動作しています |
| レイヤー固定: 本体の版が一致しないので取得方式で動きます | 取得して重ねる方式で動作しています |
| レイヤー固定: 表示開始レイヤー番号の位置を本体の描画から特定しました | 固定が有効になりました。直接描かせる方式のときに出ます |
| レイヤー固定: 表示開始レイヤー番号の位置を特定しました | 固定が有効になりました。取得して重ねる方式のときに出ます |
| レイヤー固定: まだ縦スクロール出来ないので位置の特定を保留します | 縦にスクロールできるだけのレイヤーがありません。素材を置くと自動でやり直します |
| レイヤー固定: 表示開始レイヤー番号を特定できませんでした | AviUtl ExEdit2 の内部の構造が変わった可能性があります |

AviUtl ExEdit2 が設定ファイルを書き込めない環境では、AviUtl ExEdit2 自体が終了時に異常終了したり、設定が保存されなかったりします。ログに次のような行が出ている場合は、本プラグインとは関係のない問題です。`C:\ProgramData\aviutl2` の下のファイルの権限を確認してください。

```
[ERROR] [Exception] CreateFileW() [C:\ProgramData\aviutl2\history.ini] failed in System::File::open() [アクセスが拒否されました。] (HRESULT: 0x80070005)
```
